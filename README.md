# AIoT Smart White Cane with AI Navigation and Haptic Feedback

## Overview

The AIoT Smart White Cane is an intelligent assistive navigation system designed to improve the safety, mobility, and independence of visually impaired individuals. The system combines embedded systems, Artificial Intelligence, computer vision, Internet of Things (IoT), and mobile technologies to provide seamless indoor and outdoor navigation.

The project was developed as a four-member undergraduate engineering project at the University of Colombo.

---

## Features

• Real-time ultrasonic obstacle detection
• Directional haptic feedback using vibration motors
• AI-powered indoor navigation using ESP32-CAM
• GPS-based outdoor navigation with Google Maps
• Voice-guided navigation through Android application
• ESP32-S3 embedded control system
• Wi-Fi communication between mobile app and smart cane
• Custom 3D-printed enclosure
• Hardware–software integration

## System Architecture

ESP32-S3 acts as the central controller.

Ultrasonic sensors detect nearby obstacles.

Three vibration motors provide directional haptic feedback.

ESP32-CAM detects indoor navigation markers using AI.

Android application provides outdoor GPS navigation through Google Maps.

Voice instructions are transmitted wirelessly to the smart cane.
